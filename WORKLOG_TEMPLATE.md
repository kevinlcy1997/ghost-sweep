# WORKLOG Template

Use this template for every new `##` milestone entry in `WORKLOG.md`.

~~~md
## YYYY-MM-DD Milestone Title

Current objective:
- Describe the current goal for this milestone.

Files inspected:
- List each file, document, or artifact you read.

Files changed:
- List each file you modified.

Commands run:
- List each command that materially changed or verified the work.

Test results:
- Record the exact outcome of the relevant verification.

Blockers:
- None.

Next steps:
- List the next immediate follow-up actions.
~~~

Rules:

- Keep this section order exactly.
- Use bullet lists in every required section.
- If a section has nothing to report, write `- None.`
- Optional sections such as `Resume instructions` may appear only after `Next steps`.
